# Nanoporous Carbon Coating of Separator Boosts Rate Capability of Cathodes in Lithium-Ion Batteries


## Folder Structure
- `SnakefileFinal.smk` [Snakemake](https://snakemake.readthedocs.io/en/stable/) file to run the postprocessing on all changed cases efficiently. 
  
- `snakemake_config.yml` Configuration file with some path definitions used by `SnakefileFinal.smk`

- `data/`
  - `raw_simulation_outputs/` contains the raw data output generated by the code. For some simulations, only the final timestep (i.e., steady-state) may be present, since the simulations were run until steady-state and only the steady-state was analyzed. The `raw_simulation_outputs/` is not included online due to size of the data. See [Usage](#usage) on how to obtain the `raw_simulation_outputs/` data.

- `input_files/` contains the input and parameter files for each case. For each case, `input.yml` is a copy of the input file provided by the user and `parameters.yml` is the complete set of parameters including default values.
  
- `results/`
  - contains the results of the postprocessing step. The different `postprocessing-outputs*` folders were generated at different instances in time. Refer to `postprocessing-outputs-final` for the most recent data. During the postprocessing, we extract data at the last time step (i.e., steady-state) along a few lines in the domain. These results are stored here in seperate folders for each case.
  
- `scripts/`
  - `plot/`
    - `figures.ipynb` is a Jupyter Notebook that can be used to recreate the Figures.
  - `postprocesing/` contains the different python files that are used to extract the desired data using [paraview](https://www.paraview.org) python scripting.

   Nik Leuenberger to obtain a copy of the `./data/raw_simulation_outputs/` folder.

    [niklausl@stanford.edu](mailto:niklausl@stanford.edu)

2. For the following steps, the easiest way to run them is to use a container as shown in the installation section of the top-level README.md.

3. Run snakemake from the top of the repository as follows
```
snakemake -n --snakefile ./papers/2026/Overlapping-Electrical-Double-Layer-in-Nanoporous-Carbon-Separator-Coating-Enhances-Rate-Capability-of-Lithium-Ion-Batteries/SnakefileFinal.smk
```
for a dry-run that will tell you what snakemake would do. You can then run actually run the steps using 

```
snakemake --snakefile ./papers/2026/Overlapping-Electrical-Double-Layer-in-Nanoporous-Carbon-Separator-Coating-Enhances-Rate-Capability-of-Lithium-Ion-Batteries/SnakefileFinal.smk --cores 1
```
where the number of cores can be changed and with all the additional desired [Snakemake](https://snakemake.readthedocs.io/en/stable/executing/cli.html) arguments to extract the data from the raw simulation data.

4. Adjust the `FOLDER` and `OUTPUT_FOLDER` paths in `./scripts/plot/figures.ipynb` to generate the figures based on the postprocessed data.
